# Agentic Loop Playground Workspace

This directory is the local repository used by the browser playground and GitHub Copilot CLI.

Start Copilot CLI here:

```shell
copilot
```

Run the focused practice tests:

```shell
npm run test:practice
```

The starter implementation intentionally fails the practice tests. Use the browser lessons to build the instructions, skills, evidence, GitHub Issues, worktrees, and pull request required by the course.
