# Playground Operating Loop

## Goal

Complete one bounded repository task with observable evidence and retain human control over the final decision.

## Observe

Use local tests, Git state, GitHub Issues, pull requests, Actions, and review findings.

## Act

Select one ready task, isolate it on a branch or worktree, use a specialized agent, and make the smallest valid change.

## Verify

Run focused tests, workspace validation, and an independent checker.

## Decide

Retry only when new evidence identifies a bounded correction. Escalate ambiguity, safety boundaries, missing permissions, or exhausted budgets.

## Stop Condition

Stop when acceptance criteria pass, a budget is exhausted, a trust boundary is crossed, or a human product, security, or merge decision is required.

## Persistent State

Use GitHub Issues for discovery and claims, pull requests for evidence and decisions, Git for implementation history, and `.workshop/progress.json` for local course progress.
